Remove a person (email) or a node (label or id); hosts refuse them

Usage: wires remove [OPTIONS] <WHO>

Arguments:
  <WHO>  A person's email, or a node's label or id (`label=<node id>` names it)

Options:
      --issuer <ISSUER>          The IdP that verifies the email: its exact `iss` (default: the one the network string names)
      --policy-ttl <POLICY_TTL>  Lifetime of the new signed policy, from now (`90d`, `12h`, … or seconds). Never shortens the current policy's expiry [default: 90d]
  -h, --help                     Print help
      --help-all                 Also list the operator and credential flags

Examples:
  wires remove alice@example.com        # a person, from every machine
  wires remove workbench                # a node, by label or id
