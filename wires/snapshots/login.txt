Sign in with your IdP (the first time with the network string: login <network>)

Usage: wires login [OPTIONS] [NETWORK]

Arguments:
  [NETWORK]  The network string your admin prints with `wires network` (the first time only: it joins this node to that network)

Options:
      --refresh                        Renew with the stored refresh token; the browser only if that fails
      --reuse                          Re-check the stored ID token; don't sign in
      --no-browser                     Print the sign-in URL; don't open a browser
      --callback-port <CALLBACK_PORT>  Fixed loopback port for the redirect (for `ssh -L` to a remote browser)
  -h, --help                           Print help
      --help-all                       Also list the operator and credential flags

Examples:
  wires login <network>       # the first time: join and sign in
  wires login                 # again, when your sign-in expires
  wires login --no-browser    # prints the URL to open elsewhere
