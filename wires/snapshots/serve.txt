Run host.json's services: check every caller, run the call, log it

Usage: wires serve [OPTIONS] <HOST_JSON>

Arguments:
  <HOST_JSON>  The host's config: the services it implements, its IdPs, push

Options:
      --check     Check HOST_JSON, print the services it implements and its IdPs; exit
  -h, --help      Print help
      --help-all  Also list the operator and credential flags

Examples:
  wires serve --check host.json
  wires serve host.json
