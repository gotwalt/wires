Register services: add, set, rm (who may call and read, which hosts)

Usage: wires service <COMMAND>

Commands:
  add   Register a new service and publish the new policy
  set   Change an existing service (each flag given replaces that list)
  rm    Drop a service and publish the new policy
  help  Print this message or the help of the given subcommand(s)

Options:
  -h, --help  Print help

Examples:
  wires service add orders-db --description "Read-only SQL over the orders database" \
    --allow analyst --reader security --host workbench
  wires service rm orders-db
