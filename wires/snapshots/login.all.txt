Sign in with your IdP (the first time with the network string: login <network>)

Usage: wires login [OPTIONS] [NETWORK]

Arguments:
  [NETWORK]  The network string your admin prints with `wires network` (the first time only: it joins this node to that network)

Options:
      --node-seed <NODE_SEED>
          Hex 32-byte seed of this node's key. Falls back to `$WIRES_NODE_SEED`, then `--node-seed-file`, then the keystore (`node.seed`)
      --node-seed-file <NODE_SEED_FILE>
          Read the node key seed (hex) from this file
      --issuer <ISSUER>
          OIDC issuer. Falls back to `$WIRES_OIDC_ISSUER`, then the network string's, then Google
      --client-id <CLIENT_ID>
          OAuth client id. Falls back to `$WIRES_OIDC_CLIENT_ID`, then the network string's
      --client-secret <CLIENT_SECRET>
          OAuth client secret (non-confidential for Desktop-app clients). Falls back to `$WIRES_OIDC_CLIENT_SECRET`, then the network string's
      --refresh
          Renew with the stored refresh token; the browser only if that fails
      --reuse
          Re-check the stored ID token; don't sign in
      --no-browser
          Print the sign-in URL; don't open a browser
      --callback-port <CALLBACK_PORT>
          Fixed loopback port for the redirect (for `ssh -L` to a remote browser)
  -h, --help
          Print help
      --help-all
          Also list the operator and credential flags

Examples:
  wires login <network>       # the first time: join and sign in
  wires login                 # again, when your sign-in expires
  wires login --no-browser    # prints the URL to open elsewhere
